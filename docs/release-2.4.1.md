# scrcpy-ez 2.4.1 — 应用读取与投屏流畅度优化

本版包含最新的设置分类，以及自动平滑的 **1 帧／2 帧缓冲上限选择**。基于 scrcpy 5.0.1，提供 Windows x64 发行包。

## 更新内容

- **应用搜索与大列表扩展**：应用数量保护上限由 **500 提高至 10,000**，面向安装上千应用的设备扩展读取能力。支持按应用名、包名、拼音全拼／首字母／混拼／部分前缀搜索（既有搜索能力保留）；本版优化大列表分批显示、可见区域图标加载和后台刷新，减少读取进度更新对搜索结果与滚动位置的干扰。
- **动态读取与图标优化**：根据应用数量、有线／无线连接及已观察到的处理耗时动态安排读取超时；列表与图标分阶段处理，图标仍在读取时即可使用已取得的列表，部分图标失败时保留可用列表并支持重试。图标缓存与可见区域优先加载减少重复工作；读取状态移至应用窗口底部并淡出，通知界面不再显示无关的应用读取提示。
- **设备识别兼容**：补充 USB／无线调试切换、发现和配对异常的处理，保留正常识别路径。
- **设备原生规格**：读取设备支持的分辨率和刷新率上限，按设备生成档位和重置值；无线投屏默认 60fps，保留原生高刷选项。应用窗口自动 DPI 随尺寸调整。
- **高帧率供帧**：修正编码器工作帧率提示，避免高刷输入仍按固定 60 的工作提示配置；设备不接受时可兼容回退。
- **ABR 按实际积压介入**：区分源端、链路和接收端解码压力，取消复杂帧和微小短趋势单独触发的降档，解除码率与帧率的强制联动；恢复带退避，单项锁和双锁继续有效。
- **应用窗口真实限帧**：动态降帧实际减少输入帧，窗口拉伸和编码器重建后保留限制。
- **主投屏亮屏锁**：替代周期性模拟活动，只在主投屏期间按设置持有；退出或失联后释放，应用投屏不申请主投屏亮屏锁。
- **设置分类与自动平滑**：设置按“窗口与显示／设备与应用／画面体验”分组，平滑在底部。开启后可选 1 帧或 2 帧缓冲上限，默认关闭，旧配置默认沿用 2 帧预算；修改后重新投屏生效。

自动平滑依据编码流节奏自动调整等待，最多 32ms；1 帧偏低延迟，2 帧多一些缓冲余量，不是固定等待，也不补帧。刷新率设置仍是上限，实际输出取决于内容、设备、电脑和连接。

## 下载与升级

下载 `scrcpy-ez-2.4.1.zip` 与 `SHA256SUMS.txt`，校验后解压运行 `scrcpy-ez.exe`。推荐使用应用内更新。手动更新请先退出 EZ 与投屏并备份原目录，保留自己的 `profiles.json`、`settings.json`、root 偏好和图标缓存。

发行包仅含空设备档案，不含个人设置、设备记录、通知内容、测试应用或诊断脚本。包内 `FILE_SHA256SUMS.txt` 可校验每个文件，`SOURCE_MANIFEST.json` 记录源码和运行库来源。请整包更新 GUI、启动脚本、客户端、server 和 DLL，不与候选版混用；本版配套协议为 `5.0.1-ez2.4.1-release`。

## 验证与边界

最新功能代码通过 C 完整 20 项、Java 定向 53 项、Go 应用／桥接模块完整回归与 22 个前端测试文件；设置链路覆盖开关×帧数×有线／无线×主投屏／应用投屏 16 种组合。

此前同实现候选构建在 Windows 11、K80、Xiaomi Pad 8 Pro 和老华为上验证了适用的主投屏、应用读取及图标流程；包括软／硬解码、受控解码／链路过载、恢复和应用窗口拉伸。正式版另行重建与校验版本和配套文件，不把版本提升称为重新完成全部设备性能实测。

没有物理屏摄或光学端到端延迟测量，不保证所有场景都能达到设置上限或消除全部卡顿。Android／ROM／应用兼容性、网络和主机负载仍会影响效果；Android 10 以下保留原有 ABR 兼容旁路。
